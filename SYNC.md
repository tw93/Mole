Clean uses one reclaim estimate for ordinary and bulk candidates: allocated file blocks, internal hardlinks once, and APFS private bytes for uncompressed files where available. Sparse logical lengths, external hardlinks and fully shared clone blocks no longer inflate that estimate. Symlinks are not followed; directory metadata is excluded, compressed/unsupported private-size probes fall back to allocated bytes, and separate candidates do not claim each other's hardlinks. Real file fixtures in `tests/file_ops_size.bats` cover the boundaries. This does not change Analyze's separate occupancy semantics or establish actual filesystem free-space gains after a Trash move.

Named Application Support cache rows now reuse the process guard before sizing and at each sink. Purge keeps its seven-day activity threshold but requires a manifest, matching lockfile and installation record, retains dependency files newer than that record and live/unknown projects, and resolves Git without invoking an unconfigured Apple developer-tool shim. Game-library rows remain selectable in uninstall but do not start selected with `--with-data`.

Analyze retains its existing explorer, live scans and safe deletion. GUI growth history, treemaps and MFT scanning are Intentional differences in this batch: the CLI cache is a bounded navigation cache, and changing hardlink/clone attribution between walks is not proof of growth. A future history feature needs a separately specified baseline and stable attribution contract. Status stays a compact read-only dashboard; no extra sensors, daemon or app control surface is added. Source changes and local regression tests are not a released package or destructive third-party app acceptance.
