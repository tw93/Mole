## 2026-10-26: Blocked Windows PowerShell fallback

From `60ab99f`; fix commit `c368374d`. A managed x64 machine blocks `powershell.exe` by policy while PowerShell 7.6.7 runs, so the native launcher failed before Mole started. `cmd/mo` now tries Windows PowerShell first and `pwsh.exe` only when that host cannot be started; a host that starts is never retried on the other, so a command cannot run twice. `Get-WmiObject` was replaced by `Get-CimInstance` in `lib/core/base.ps1` and `bin/optimize.ps1` because PowerShell 7 implements it through implicit remoting, which starts the blocked `powershell.exe`. Entrypoints clear through `Clear-MoleScreen`, which skips `Clear-Host` when output is redirected (PowerShell 7 throws "The handle is invalid" there). `AGENTS.md` records the host order and the `Get-WmiObject` ban; `tests/Core.Tests.ps1` guards the source, and `cmd/mo/main_test.go` covers start-failure fallback and the no-retry boundary.

Verification on that machine: a built `mo.exe` ran `--version`, `--help`, `analyze --help`, redirected `clean --dry-run` (exit 0, 3.07 GB preview), `optimize --dry-run`, `status --json` and `history --json`; `uninstall --dry-run` listed apps and stopped at pagination because input was redirected. A repeat run reproduced all of them (`clean` preview 3.08 GB). Pester 6.2.0 under PowerShell 7.6.7 passed Optimize 44, UI 13, Uninstall 153 and DryRunEnvironment 7 in two consecutive runs (217/217 each); Core passed 81 with 2 failures and InstallLifecycle passed 24 with 5 failures, all where the tests themselves start the blocked `powershell.exe` or need symlink privilege. All PowerShell files parsed. `cmd/mo` and `cmd/analyze` passed five repeated Go runs. One full Go run passed `cmd/status`, but later runs failed `TestWatchHonorsIntervalAfterInitialSnapshot`: this host's wall clock advances about 989 ms per second while the monotonic sleep measures 1.0005 s, and that test compares JSON wall-clock timestamps. The production interval is unchanged; the test result is a host clock artifact, not a regression from this batch.

PowerShell 5.1 could not run here because the machine blocks it; no 5.1 result, CI run or release exists for this batch. No real cleanup, uninstall or UAC prompt was performed. The released V1.39.0 package still has the old launcher and WMI calls.
