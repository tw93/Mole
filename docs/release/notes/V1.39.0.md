# Roomy V1.39.0 Release Notes

Launch scope: CLI

## Compatibility And Scope

Roomy V1.39.0 ships the supported command-line product for macOS. The production release remains scoped to Homebrew, the install script, tagged GitHub releases, and Darwin helper binaries for `analyze` and `status`.

RoomyUI remains outside the public release channel for this tag. Native app builds may still be used for local preview and UX validation, but this release does not publish a `.app`, `.dmg`, or notarization artifact.

## User-Visible Changes

This release focuses on making the CLI product release-ready: bounded duplicate scanning, more resilient status JSON collection, hardened profile import/export handling, and clearer dry-run and maintenance behavior across destructive workflows.

The sales site and release documentation now present Roomy as a CLI-first Mac maintenance product with preview-first cleanup, local execution, audit logs, and repeatable workflows for technical Mac users and small teams.

## Safety And Destructive Workflows

Destructive workflows keep dry-run coverage, protected-path checks, traversal and symlink refusal, sudo-boundary handling, restore previews, and operation/deletion logs as launch gates. Release preflight also scans for unsafe raw deletion usage.

Profile archive import now validates tar entries before extraction and rejects symlinks, special files, path traversal, and unsafe replacement paths.

## Install, Update, And Remove

The release gate verifies that `VERSION` in `roomy` matches `V1.39.0`, that the tag is not reusing an older commit, and that the public release workflow publishes only CLI helper assets, Homebrew tarballs, checksums, provenance metadata, and GitHub source archives.

Homebrew install, script install, update behavior, remove behavior, and reinstall coverage are required by the clean-machine drill before this tag can be promoted from staged prerelease to stable/latest.

## License And Source

Roomy is documented as a GPL-3.0 Roomy-branded fork with upstream Mole attribution. Public distribution uses the Roomy namespace, includes `NOTICE`, and avoids upstream Mole support channels or brand claims.

The release manifest points to the corresponding source for `V1.39.0`, and the release archive preserves the GPL-3.0 license text and attribution notice.

## Known Limitations

RoomyUI is preview-only for V1.39.0. The native app still needs a separate release decision covering Developer ID signing, notarization, privileged helper deployment, update/rollback behavior, clean-machine QA, and support documentation before it can be sold as a downloadable macOS app.

The final stable/latest release must be cut from a clean worktree and promoted only after the tag-specific clean-machine drill record passes.

## Verification

- Clean-machine drill record: `clean-machine-drill-V1.39.0.md` must be uploaded by the release workflow and verified by `scripts/check-public-release.sh --tag V1.39.0 --final --record clean-machine-drill-V1.39.0.md` before stable/latest promotion.
- SHA256SUMS/checksum evidence: generated by the release workflow and included in the release manifest with source archive, helper binary, and Homebrew tarball SHA-256 values.
- Artifact attestation evidence: generated by the release workflow and summarized in the release manifest.
