How it works

Three steps. No black box.

1

Scan

Roomy groups caches, logs, app remnants, build artifacts, installers, and large files by cleanup category.

2

Preview

Dry-run output shows candidates, protected skips, estimated space, and risk limits before anything changes.

3

Clean

Approved actions run locally, write operation logs, and keep eligible cleanup items recoverable through Trash-backed restore flows.

FAQ

Common questions.

Is Roomy a native Mac app?

The production product today is the command-line tool. RoomyUI remains a preview surface in this repository and is not part of the public release channel yet.

Does Roomy delete files automatically?

No. Use dry-run previews first, then approve the cleanup plan. Higher-risk paths are skipped, refused, or capped by default.

How is this different from CleanMyMac?

Roomy is narrower and more inspectable. It focuses on local cleanup, uninstall, disk analysis, status, reports, schedules, and restore flows instead of broad security or consumer-suite features.
