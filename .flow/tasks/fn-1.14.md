# fn-1.14 Design system and animations framework

## Description
Create the foundational design system and animation framework that will be used throughout Tonic. This establishes the visual language and ensures consistent, delightful UX.

**Key Actions:**
1. Define color palette (gradients, accents, semantic colors)
2. Create typography system (fonts, sizes, weights)
3. Build glassmorphism components (translucent cards, blur effects)
4. Implement animation primitives (Hero, spring, ease curves)
5. Create reusable SwiftUI components (Cards, Buttons, Progress)
6. Design SF Symbols icon set
7. Establish spacing and layout guidelines
8. Create light/dark mode themes
