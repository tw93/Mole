# Mole

用 AI 帮你一次清理出几十 GB 电脑垃圾，还能卸载软件、清理残留，让电脑更加轻快。

装好后直接问「帮我清理一下电脑」「帮我优化一下我的电脑」「帮我卸载这个软件」，Agent 会自动到系统里找到你的垃圾，全部列出来给你看，你同意以后再清理。

电脑上还没装 Mole 的话，Agent 会先问你，同意后帮你装好。

当然，如果更喜欢 App 形态，可以用官方的界面版本 [Mole](https://mole.fit/zh/)。

安装插件：`dsh plugin --profile <name> add dsh-mole`。

官方开源地址：https://github.com/tw93/Mole
